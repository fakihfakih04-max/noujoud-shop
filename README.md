# NOUJOUD | نجود — GitHub Pages

## النشر
1. افتح GitHub وأنشئ مستودعاً عاماً باسم `noujoud-shop`.
2. ارفع **محتويات هذا المجلد فقط** إلى جذر المستودع (`index.html`, `app.js`, `styles.css`, `catalog.js`). لا ترفع ملفات الإدارة أو السائق.
3. من Settings → Pages اختر Deploy from a branch → `main` → `/ (root)` ثم Save.
4. افتح الرابط الذي يظهر في Pages، وعادةً يكون `https://USERNAME.github.io/noujoud-shop/`.
5. انسخ الرابط إلى منشور Facebook وصفحة نجود.

## تحديث المنتجات
ملف `catalog.js` هو الكتالوج العام. افتحه وعدّل المنتجات/الأقسام/المناطق، أو استخدم النسخة المحلية للمالك مع زر «تصدير كتالوج GitHub Pages» ثم استبدل `catalog.js` في GitHub.

**تنبيه:** الكتالوج يبدأ بلا منتجات تجريبية لتجنب نشر أسعار ومخزون غير حقيقيين. أسعار التوصيل الموجودة أمثلة يجب أن تؤكدها نجود قبل النشر. الصور المضمنة في `catalog.js` قد تجعل الملف ضخماً؛ يفضل رفع صور مضغوطة في مجلد `images/` واستخدام مساراتها.

**مهم:** GitHub Pages لا يملك قاعدة بيانات أو تسجيل دخول آمناً. طلب الزبون لا يصل إلا عندما يضغط إرسال في WhatsApp. لا ترفع `admin.html`, `admin.js`, `driver.html`, `driver.js` أو بيانات الزبائن إلى المستودع العام. الفواتير والتقارير في النسخة المحلية لا تجمع طلبات زبائن الأجهزة الأخرى.
